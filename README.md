# Paws & Poses

A scroll-driven 3D website: one canvas, one scene, one camera, three floating islands.
Built with React, React Three Fiber, GSAP ScrollTrigger and Lenis.

## Run it

```bash
npm install
npm run dev              # http://localhost:5173
npm run build            # production build in dist/
npm run preview          # serve that build locally
npm run optimize:model   # rebuild the 3D model (only after changing it — see below)
```

The site uses real URLs (`/experiences`, `/about`, `/contact`), so the host must serve
`index.html` for unknown paths (the usual single-page-app rewrite).

## Where things are

```
assets/source/          Raw originals — not shipped. The Blender export and source photos.
public/
  models/islands.glb    The web-ready 3D model (generated by `npm run optimize:model`)
  images/               Logo, owner photos, Experiences page pictures
scripts/
  optimize-model.mjs    Builds islands.glb from the Blender export
  model/settings.mjs    …what it cuts, repaints and how small it makes things
  model/surgery.mjs     …removing parts of a mesh
  model/repaint.mjs     …recolouring parts of a texture
src/
  content/site.ts       ALL copy, links and contact details
  pages/                Home, Experiences, About, Contact
  components/           Navbar, Footer, Loader, Owner section, shared UI
    Stage/              The pinned full-screen 3D section of the home page
  scene/                The 3D world (see below)
  lib/                  Shared state and behaviour (scroll, explore mode)
  styles/               Plain CSS; design tokens are in src/index.css
```

### Common edits

| I want to change…                          | Edit                                              |
| ------------------------------------------ | ------------------------------------------------- |
| Any text, link, email, phone, booking URL  | `src/content/site.ts`                             |
| An island's angle, size or height          | `ISLANDS` in `src/scene/config.ts`                |
| How islands float / travel between slots   | `MOTION`, `LAYOUT` in `src/scene/config.ts`       |
| The angle explore mode opens at            | `EXPLORE_START` in `src/lib/explore.ts`           |
| What a puppy does on hover                 | `tricks` in `ISLANDS` (`src/scene/config.ts`)     |
| Flowers, toys and where they sit           | `src/scene/props/plantings.ts`                    |
| The cottage                                | `src/scene/props/cottage.ts`                      |
| Colours and type                           | `src/index.css`, `src/styles/`                    |

## How the home page works

`components/Stage/` is a tall scroll track holding a sticky full-screen stage: the canvas plus
three text panels (hero, yoga, paint). `useStageScroll` turns scroll position into a smoothed
island index (`stage.progress`, 0 → 2) and fades the panels to match. The 3D scene reads the same
value, so text and islands stay in step.

`lib/stage.ts` is the bridge between the page and the scene: a plain object for values that
change every frame (scroll progress, pointer, explore state) and a tiny store for the few values
React components react to.

**Explore mode** (`lib/explore.ts`, `Stage/ExploreOverlay.tsx`): the "Explore the island" button
moves the current island to the centre, where it can be dragged to rotate and zoomed.
"Meet the puppy" brings the camera face to face with the puppy.

## The 3D scene (`src/scene/`)

| File                      | Job                                                                         |
| ------------------------- | --------------------------------------------------------------------------- |
| `Experience.tsx`          | The canvas. Pauses rendering when scrolled out of view.                     |
| `config.ts`               | All the tuning knobs.                                                       |
| `layout.ts`               | Converts screen size into world-space positions, so composition holds on every screen. |
| `useIslandModel.ts`       | Loads the GLB and groups its nodes into islands by name, then adds the props. |
| `Islands.tsx`             | Places and moves the islands each frame.                                    |
| `Clouds.tsx`, `Lighting.tsx`, `CameraRig.tsx` | What they say.                                          |
| `props/clay.ts`           | Shared palette, material and helpers for hand-built props.                  |
| `props/flowers.ts`, `objects.ts`, `cottage.ts` | The hand-built props themselves.                       |
| `props/plantings.ts`      | Which props go on which island, and where.                                  |
| `props/animate.ts`        | Flowers sway, the heart floats.                                             |
| `puppy/animatePuppy.ts`   | Puppy motion: breathing, plus one short action per hover.                   |
| `puppy/updatePuppy.ts`    | Finds the puppy on screen (hover, close-up camera) and runs its animation.  |

The camera never travels: the islands ride an off-screen wheel, so scrolling lifts one away while
the next swings up into place.

The puppies have no skeleton. Their tail, ears and head move by bending regions of the mesh in the
vertex shader; the regions are measured as fractions of the mesh's bounding box in
`puppy/animatePuppy.ts`.

## The 3D model

The Blender export (`assets/source/full_environment.glb`, ~180 MB, ~4 million triangles) is far
too heavy for a browser, and parts of it were weak. `npm run optimize:model` produces the ~5 MB
file the site loads, and along the way:

- **cuts out** the original house, some flowers, the pebbles, one pillar and the underside of the
  hero island;
- **flattens** the bumps of the yoga platform that sit under the yoga mats;
- **repaints** the hero island's ground and a few muddy petals;
- simplifies every mesh and shrinks every texture.

The cut-out parts are replaced by clean hand-built props in `src/scene/props/`. The two halves must
agree: a cut in `scripts/model/settings.mjs` is covered by a prop in `props/plantings.ts`.

If you re-export from Blender:

- keep node names starting with `hero`, `yoga`, `lamp`, `paint` or `cloud` — that is how the site
  knows which island a mesh belongs to;
- if the hero island's shape changed, re-check the cut regions and the prop positions.

The three pictures on the Experiences page (`public/images/experience-*.webp`) are renders of the
puppies and props from this scene, saved as images.
